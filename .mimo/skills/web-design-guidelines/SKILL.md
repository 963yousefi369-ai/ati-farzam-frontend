# Web Interface Guidelines

Review files for compliance with Web Interface Guidelines.

## Guidelines Source
Fetch fresh guidelines before each review:
```

```

## Key Principles
- Visual hierarchy — clear heading differentiation
- Spacing consistency — systematic padding/margins
- Color usage — stick to design tokens
- Typography — systematic scale
- Layout consistency — unified container patterns
- Border radius/shadow — use token system
- Responsive design — mobile-first
- RTL support — no LTR-only assumptions
- Component reuse — avoid duplicate patterns
