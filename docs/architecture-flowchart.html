ارتباط بین ماژول‌ها (Module Communication)
نقشه ارتباطات
Auth ↔ API Layer
توکن JWT از AuthStore به تمام API calls ارسال می‌شود. Auto-refresh در 401. Logout در refresh failure.
Cart ↔ Checkout
آیتم‌ها از CartStore خوانده شده، در checkout به order تبدیل می‌شوند. Stock hold/release مدیریت می‌شود.
Settings → Layout
تنظیمات Django + CMS در layout اصلی خوانده شده و از طریق React Context به تمام کامپوننت‌ها منتشر می‌شود.
Chatbot ↔ Auth
توکن کاربر به چت‌بات ارسال می‌شود برای شخصی‌سازی پاسخ‌ها. Session مستقل از auth.
Tracking → همه ماژول‌ها
سیستم tracking به صورت مستقل از تمام ماژول‌ها رویداد دریافت می‌کند. Fire-and-forget — هیچ‌وقت UX را مختل نمی‌کند.
ISR + Revalidation
صفحات CMS با ISR کش می‌شوند. بک‌اند Django با ارسال secret به /api/revalidate کش را باطل می‌کند.
